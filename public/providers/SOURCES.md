# Where each logo came from

Logos are trademarks of their owners, used only to show which bank / provider
an account belongs to. All files are 256×256 images. Every choice was checked
against the provider's official Play Store app (developer verified).

| Source | Providers |

| Website icon (brand mark; app icon is a sub-brand, seasonal or has a "MY" badge) | maybank, maybank-gold, cimb, ambank, bank-rakyat, affin, ocbc, hsbc, standard-chartered, al-rajhi, gxbank, aeon-bank, tng, grabpay, tabung-haji, stashaway, wahed, versa, rakuten-trade, luno, habib, epf |
| Wikimedia Commons logo, symbol cropped to a square | principal |

Note: `npm run logos -- --force` re-downloads website icons and would replace
the choices above; run it without `--force` instead.
